# Planning

Inspect existing implementation and decisions first. State the goal,
non-goals, scope, acceptance checks, risks and recovery approach.
Split into small deliverables, each with a title, contract, author context,
safe scope and prerequisite keys. A dependency graph must be acyclic.
Use plan dry-run before apply; do not treat a proposed plan as accepted work.
Choose next work from actual task states, not a stale summary.
