# Change Review

Read the actual relevant diff, callers, contract and test evidence.
Trace suspected defects into executable scenarios before stating findings.
Prioritize impact, give source locations and explain the failure mechanism.
Separate demonstrated defects, risk hypotheses and style preferences.
State unexercised surfaces and conflicting evidence.
Do not implement fixes during a report-only review or claim independence
from a different role label within the same implementation context.
