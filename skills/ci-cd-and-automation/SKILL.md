# Pipeline Boundaries

Read the project's actual workflows, triggers, credentials and supported matrix.
Trace which inputs, artifacts and privileges cross each job boundary.
Preserve least privilege, reproducibility and clear failure reporting.
Do not weaken tests, widen secrets or add remote side effects implicitly.
Validate syntax and relevant owned fixtures when authorized.
Separate editing a workflow from authorizing its production execution.
