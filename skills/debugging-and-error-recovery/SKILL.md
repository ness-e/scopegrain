# Recovery

Classify completed, partial, unexpected and failed work using actual files
and recorded state. Preserve successful outputs and their provenance.
Resume if inputs and ownership remain valid; retry only an identified
transient failure; change strategy when the cause invalidates the approach.
Escalate when authority, missing evidence or repeated uncertainty blocks work.
Do not clear locks, discard user work or reset budgets automatically.
Save what happened, what remains and the exact next safe action.
