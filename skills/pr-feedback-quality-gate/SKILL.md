# Review Feedback

Read each comment and inspect its claimed executing path.
Separate verified defects, valid risks and unsupported preferences.
Batch coherent corrections with exact regression cases and preserved scope.
Run authorized narrow checks and inspect the full resulting diff.
Respond with evidence, unresolved questions or a technical reason to disagree.
Submitting replies, pushing and changing PR state need explicit authority.
