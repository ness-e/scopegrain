# Research

`module`: state one concrete question, affected area and decision to
support. Start with repository evidence. For external APIs use applicable
official documentation when network permission exists. Record sources,
scope, observed facts, hypotheses and unresolved uncertainty.

`synthesis`: compare existing research results, contradictory evidence,
alternatives, costs and failure modes. Ask the owner to decide matters of
authority, scope or product direction; do not disguise a choice as fact.

Use a research artifact for findings and a decision artifact for approved
choices. References and link titles are not proof that a URL was read.
No installation, web access or repository modification is implied.
