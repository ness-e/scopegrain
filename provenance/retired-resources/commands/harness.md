# Harness Health

Run read-only catalog validation and project doctor. Inspect command
dependencies, role boundaries, profile selection, generated resources,
path safety, catalog drift and the actual scope of enforcement.

Distinguish a missing native capability from a corrupt local resource.
Check that instructions do not imply automatic shell execution,
authenticated reviewer identity, universal tool interception or sandboxing.
Inspect provenance statuses before recommending optional content.
Report evidence and a repair proposal; never relax a safety rule simply
to make a health check green.
