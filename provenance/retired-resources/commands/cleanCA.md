# Code and Architecture Review

Inspect exactly the requested files or discovered modules. This command
is report-only. Evaluate intention-revealing names, coherent abstraction
levels, explicit side effects, dependency direction and testable boundaries.

Use the language's idioms and real constraints; line counts and argument
counts alone do not prove a defect. Explain concrete maintenance or
behavioral consequences with source evidence.
Separate actionable findings from preferences, offer scoped remedies
and save a review in the harness workspace. Do not apply the remedies.
