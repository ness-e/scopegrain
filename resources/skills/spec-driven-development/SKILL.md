# Specification

Inspect the current behavior, callers, tests and product constraints.
Write examples of intended behavior, failures and explicit exclusions.
Define compatibility, security and recovery obligations where relevant.
Make acceptance falsifiable and identify the exact proposed checks.
Resolve consequential unknowns with the owner rather than silently choosing.
Store the spec in the harness workspace; link it from the task contract.
