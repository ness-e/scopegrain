# Implementation Plan

State verified existing behavior, required gap and approved design.
For each task give inputs, files, exact interface, acceptance cases,
dependencies, authority and proposed verification commands/cwds.
Keep implementation slices small and avoid unrelated work.
Store the plan inside configured harness paths and dry-run before apply.
Do not delegate a choice that still needs exploration or owner approval.
