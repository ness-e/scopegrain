# Deep Review

Inspect the full relevant diff, public contracts, callers and failure paths.
Trace data, authority, ownership, persistence and concurrency where relevant.
Check adversarial and interrupted states as well as ordinary success.
Compare every acceptance claim with actual verification evidence.
Report evidenced findings first and list unexercised surfaces.
Do not manufacture quality scores or confuse your own implementation
context with an independent reviewer.
