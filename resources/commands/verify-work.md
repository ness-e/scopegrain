# Verify Work

Discover actual acceptance criteria, project scripts, supported environments
and the applicable permission to run checks. If execution is reserved for
the owner, provide exact commands and await complete output.

Quick mode selects the smallest adequate checks for the changed surface.
Certify mode covers the agreed integration gate and compatibility boundaries.
Neither mode changes the quality floor or authorizes installations/services.

Record command, environment, scope, exit code, raw output, failures and skips.
Treat a diagnostic result separately from a claim of correction.
Report unavailable or unexecuted checks honestly. Do not fix the product,
approve a release or claim independent review within this procedure.
