# Plan Work

Inspect existing plans, specifications and implementation first. Identify
the actual gap; do not produce another plan for work already completed.
Require a settled specification, outcome evidence and explicit design approval.
For small fixes use a proportionate contract, not empty ceremony.

Produce tasks with stable keys, bounded scopes, acceptance cases, dependencies,
required capabilities and exact checks discovered in this project.
Parallelize only independent work with disjoint writes. Mark unknowns blocked.
Do not select paid models, budgets or external effects without approval.

Present the complete plan and operational destinations for confirmation.
Persist only through available approved harness operations. Do not execute
tasks or call an unavailable planning tool. Return plan identity and next gate.
