# Triage Work

Read the owner's actual backlog conventions, persisted tasks, dependencies
and recent evidence. Include completed/closed locations where relevant.
Distinguish dependency readiness, priority, severity and business value.

Recommend a bounded next set with reasons, missing inputs and tradeoffs.
Do not invent scores, deadlines, owners or agreement on scope.
Surface conflicting priorities and ask the owner to decide.

Return recommendations and references. Do not create tasks, edit priorities,
reopen closed work or start implementation as part of this procedure.
