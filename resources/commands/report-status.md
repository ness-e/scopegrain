# Report Status

Read current tasks, plans, sessions and cited verification artifacts.
Separate completed, active, blocked, failed, unexecuted and unknown work.
Do not infer execution, publication or pull-request lifecycle from a summary.

Report changed scope, latest verified results, remaining gates and next action.
Preserve historical evidence as historical; do not rerun derivations merely
to reformat them. A passing subset is not a passing full suite.

In guided interaction, explain the current stage and ask which consequential
next action the owner wants. Do not choose or execute it implicitly.
Return a status report; any saved copy is an explicit harness artifact.
