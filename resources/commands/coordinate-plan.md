# Coordinate a Plan

Load the persisted plan, current task states, approvals, available host
capabilities and remaining authorized budget. Reuse completed/in-flight work.
The dependency scheduler does not prove that any agent has executed.

Prepare one bounded brief per ready task: inputs, interface, write scope,
acceptance, exact checks and return artifacts. Settle ambiguous contracts
before dispatch. Keep decisions, critical policies and final approval with
the lead; read-only roles return findings for the lead to persist.

Delegate only through an actually available authorized host capability.
Without it, propose supervised sequential execution; do not claim fan-out.
Inspect every returned diff and artifact before accepting results. Preserve
partial progress, stop at gates and reconcile uncertain effects before retry.
Return completed, active, blocked and next work; do not publish automatically.
