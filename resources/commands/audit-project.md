# Audit a Project

Agree scope, relevant risks, environments, permitted checks and report path.
Inspect actual entrypoints, boundaries, dependencies, persistence and tests.
Sample explicitly when exhaustive inspection is infeasible; name omissions.

Separate reproduced defects, static findings, hypotheses and unavailable
evidence. For each issue provide location, prerequisites, impact and a
discriminating check or regression case. Use qualitative FMEA unless
probabilities and scoring were independently justified and approved.

Return prioritized findings and decisions needed. Do not modify the project,
install scanners, scan external systems or publish security details implicitly.
The lead records the report in the approved harness workspace.
