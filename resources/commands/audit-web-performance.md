# Audit Web Performance

Confirm the web surface, workload, devices, relevant user outcome and
permission to start a server/browser or contact an external URL.
Inspect static risks separately from measured runtime behavior.

Quick mode targets the agreed critical path; deep mode expands to the
agreed representative scenarios. Neither implies permission to install tools.
Record environment, command, input, raw results, variance and missing coverage.
Use existing baselines; do not invent thresholds, scores or improvements.

Return prioritized findings and evidence gaps, not an unqualified certificate.
Do not claim real-user performance or accessibility conformance from a
synthetic run, screenshot or static review. Do not modify the product here.
