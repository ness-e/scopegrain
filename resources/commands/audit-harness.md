# Audit the Harness

Inspect canonical registry, aliases, links, profiles, policies, snapshots
and generated proposals against their consumers and actual tests.
Check source/projection paths, byte limits, approvals, temporary ownership,
lock/crash behavior and command/role responsibility boundaries.

Validate model-facing instructions and tool claims against available schemas.
Distinguish generated configuration, documented compatibility and a native
pilot. Read-only annotations and role text do not enforce access control.

Report drift, unsupported capabilities and corrections with evidence.
Do not auto-repair resources, activate integrations or import archived rules.
Provide a public rename map before changing interfaces.
