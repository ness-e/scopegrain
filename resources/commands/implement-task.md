# Implement One Task

Read the real task, revision, approved specification/design and current code.
Confirm readiness, authority, scope, acceptance and available verification.
An unknown task, missing approval or ambiguous product decision blocks work.
If the required methodology capability is unavailable, report that gap;
do not fabricate an approval or silently bypass the gate.

Create a causal failing regression before changing behavior. Apply the
smallest upstream fix, preserve unrelated work and run only authorized checks.
After repeated failure follow research-escalation; do not retry blindly.

Inspect the complete diff and raw verification evidence. Obtain independent
review or an explicit scoped waiver; authorship is not independent review.
Record actual state and continuation in harness paths. Stop after this task;
neither publication nor the next task is implicitly authorized.
