# Evidence

- Distinguish observed facts, inference and speculation.
- Name the exact command, working directory, result and inspected artifact.
- Never mark an unexecuted check as passing.
- An attestation records a claim; it does not authenticate execution.
- Static inspection cannot establish all runtime or population properties.
- A stale passing result does not prove a changed implementation.
- Report missing, corrupted or unavailable evidence instead of suppressing it.
