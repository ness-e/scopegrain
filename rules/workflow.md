# Recorded Workflow

- Check existing behavior before planning.
- Read the actual task state and revision before mutation.
- Respect dependency readiness; unrecorded success is not CLOSE.
- Edits require ACT; changed work needs new verification and review.
- Preserve partial work and evidence across interruption.
- Write artifacts only after a displayed plan and explicit apply/consent.
- Stop at the agreed boundary rather than launching unrelated tasks.
