# Status

Summarize the active goal, plan, task states, blocked dependencies,
verification evidence, review status and last continuation record.
Use stored records and inspectable local evidence; surface corruption.

Separate completed work, current work, blockers and next action.
Report stale configuration and unavailable host capabilities.
A previous passing check is not proof after implementation changes.
Keep the report concise and do not mutate task states to match a story.
