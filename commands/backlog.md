# Backlog

Read existing configured plans and tasks, including malformed-entry
warnings. Identify active, blocked, ready and closed work from actual
records. Do not assume a Markdown backlog path or a project's ID taxonomy.

Recommend the next actionable item using user priority, dependencies,
risk and unfinished work already in progress. State the reasoning and
any missing evidence; do not assign fabricated numerical scores.
Do not edit priorities or create tasks merely by displaying this view.
If no plan exists, propose planning rather than inventing completed work.
